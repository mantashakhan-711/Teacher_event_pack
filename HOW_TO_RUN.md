# HOW TO RUN — Python

### Requirements
- Python 3 installed
- Google Chrome

### Steps
1. Open this folder in VS Code.
2. Open Terminal in this folder.
3. Run:

```bash
python server.py
```

If `python` does not work on Windows, try:

```bash
py server.py
```

4. Wait for the server to start.
5. Open Google Chrome.
6. Visit:

`http://localhost:5000`

### Stop the server
Press `Ctrl + C` in the terminal.
